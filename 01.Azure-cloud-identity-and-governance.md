```text

      ↓
Microsoft Entra ID
      ↓
Default User
      ↓
Tenant Root Management Group
```

|---|---|

# 5. Token-Based Authentication Flow

Modern cloud platforms use token-based authentication systems.

---

# Authentication Flow

```text
User Login
      ↓
Entra ID Validates Identity
      ↓
Authentication Token Generated
      ↓
Access Granted to Azure Portal
```

---

## What is a Token?

A token is a temporary digital credential used to validate:
- Identity
- Session
- Permissions

---

## Token Benefits

| Benefit | Description |
|---|---|
| Improved security | Credentials are not repeatedly exposed |
| Faster access validation | Session reuse |
| Scalable authentication | Enterprise-ready authentication |

# 13. Role-Based Access Control (RBAC)

RBAC is Azure’s authorization model used to control resource access.

---

## RBAC Workflow

```text
User
   ↓
Assigned Role
   ↓
Defined Scope
   ↓
Resource Access
```

---

## Why RBAC is Important

- Least privilege access
- Centralized access control
- Enterprise-grade security
- Simplified governance

---

# Common Azure Roles

| Role | Permission |
|---|---|
| Reader | Read-only access |
| Contributor | Create & modify resources |
| Owner | Full administrative access |

---

# 14. Azure Roles vs Entra Roles

This is one of the most important enterprise IAM concepts.

---

# 14.1 Entra Roles

Manage identity-related operations.

---

## Examples

| Entra Role | Purpose |
|---|---|
| Global Administrator | Full identity control |
| User Administrator | Manage users |
| Privileged Role Administrator | Manage privileged access |

---

# 14.2 Azure Roles

Manage Azure cloud resources.

---

## Examples

| Azure Role | Purpose |
|---|---|
| Owner | Full resource management |
| Contributor | Resource modification |
| Reader | View-only access |

---

# Core Difference

| Entra Roles | Azure Roles |
|---|---|
| Identity Management | Resource Management |
| User & IAM Control | Cloud Resource Control |
| Entra ID Scope | Azure Resource Scope |

---

# 15. Global Administrator Role

The Global Administrator is the highest privilege role inside Microsoft Entra ID.

---

## Responsibilities

- Manage users
- Configure authentication
- Assign Entra roles
- Manage identity security

---

## Important Clarification

Global Administrator does NOT automatically have full Azure resource ownership.

Identity management and resource management are separate domains.

---
