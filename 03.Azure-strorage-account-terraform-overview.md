# 1. Introduction to Enterprise Cloud Storage

Modern cloud applications require highly scalable, secure, durable and globally accessible storage systems.

Cloud storage platforms are designed to handle:
- Structured data
- Unstructured data
- Shared file systems
- Backups
- Logs
- Media files
- Application state data

# 16. LRS vs ZRS vs GRS vs GZRS

---

# 16.1 LRS (Locally Redundant Storage)

Stores multiple copies inside a single datacenter.

---

## Architecture

```text
Single Datacenter
      ↓
3 Copies
```

---

## Advantages

- Lowest cost
- Basic redundancy

---

## Limitation

Datacenter-level failure risk.

---

# 16.2 ZRS (Zone Redundant Storage)

Stores copies across multiple availability zones within the same region.

---

## Benefits

- Zone failure protection
- Higher availability

---

# 16.3 GRS (Geo-Redundant Storage)

Replicates data to a secondary region.

---

## Example

```text
Primary Region → Secondary Region
```

---

## Benefits

- Regional disaster recovery
- Business continuity

---

# 16.4 GZRS (Geo-Zone Redundant Storage)

Combines:
- Zone redundancy
- Geo redundancy

---

## Highest Resilience Option

Provides:
- Zone-level protection
- Regional disaster recovery

---

# Important Interview Comparison

| Replication Type | Protection Level |
|---|---|
| LRS | Datacenter |
| ZRS | Zone |
| GRS | Region |
| GZRS | Zone + Region |

# 18. Hot, Cool & Archive Tier Deep Dive

---

# Hot Tier

- Frequently accessed data
- Higher storage cost
- Lower access cost

---

# Cool Tier

- Less frequently accessed data
- Lower storage cost
- Higher access cost

---

# Archive Tier

- Rarely accessed data
- Cheapest storage
- Retrieval delay

---

# Example

| Data Type | Recommended Tier |
|---|---|
| Active application logs | Hot |
| Monthly reports | Cool |
| Old backups | Archive |
